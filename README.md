# 🚀 Coding Tracker

A simple and user-friendly web application to track daily coding practice and improve consistency.

## ✨ Features
- ➕ Add coding problems
- ✅ Mark problems as completed
- ❌ Delete tasks
- 📋 View all added problems

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ How to Run

This project was built to practice JavaScript fundamentals and track coding progress.
